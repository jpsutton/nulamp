# nulamp

A cross-platform audio and video player that plays classic Winamp 2.x skins (`.wsz`).

nulamp is an independent, clean-room implementation written from the specification in
[`spec/`](spec/README.md). It is not affiliated with, and does not contain code or artwork from,
the original player. Its default skin is generated by [`tools/skingen`](tools/skingen) and its
icon by [`tools/icongen`](tools/icongen).

## Features

- Classic skins: main window, equalizer and playlist editor, windowshade modes, double size,
  docking and snapping, `region.txt` window shapes, skinned cursors, the skin's bitmap fonts.
  Text is never antialiased.
- Playback: MP3, FLAC, Ogg Vorbis, Opus, WAV/AIFF, AAC/ALAC in MP4, MIDI (SoundFont), tracker
  modules (with libopenmpt), and HTTP/SHOUTcast/Icecast streams with in-band titles. Gapless
  playback, fades, ReplayGain, a 10-band equalizer and the classic spectrum analyzer and
  oscilloscope.
- Video: AVI, Matroska/WebM, MP4/MOV, FLV, WMV, MPEG and more through FFmpeg, in the skinned
  video window, kept on the audio clock, with zoom, full screen, aspect ratio and audio/video
  track choice.
- Playlists: M3U/M3U8, PLS, XSPF, B4S, ASX, WPL, ZPL; title formatting; tag reading and writing;
  bookmarks; jump to file; queue.
- Media library: a local SQLite library with folder watching and search, plus the music,
  movie, TV and video libraries of a Jellyfin server (10.9 or newer), behind a provider
  interface for other sources
  ([`docs/media-library.md`](docs/media-library.md)).
- Plugins: a C ABI for decoders, effects, visualizations and general modules
  ([`docs/plugins.md`](docs/plugins.md), [`include/nulamp_plugin.h`](include/nulamp_plugin.h)),
  plus built-in scripted effects ([`docs/scripted-dsp.md`](docs/scripted-dsp.md)).
- Remote control: the classic command-line switches against a running instance
  (`nulamp /?`), MPRIS on Linux, global hotkeys, tray icon.
- Imports the settings, EQ presets, bookmarks and playlist of an existing Winamp installation
  (`--import-winamp <dir>`, or automatically at the first start).

## Downloads

[Releases](https://github.com/jpsutton/nulamp/releases) have packages for Ubuntu and Arch Linux,
an AppImage for other Linux distributions, and builds for Windows and macOS. Release files are
signed with the nulamp release key ([`packaging/nulamp-signing-key.asc`](packaging/nulamp-signing-key.asc),
fingerprint `928D 2737 FE5D 5FA5 0DC6  EBAC E5F8 0263 48A3 8A7F`): `SHA256SUMS.asc` covers every
file, and the Arch packages are signed directly.

To check a download, fetch `SHA256SUMS` and `SHA256SUMS.asc` from the same release, then:

```bash
gpg --import packaging/nulamp-signing-key.asc   # or the key file attached to the release
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS
```

**Ubuntu 24.04 or 26.04:** download the `.deb` for your release, then

```bash
sudo apt install ./nulamp_*ubuntu$(. /etc/os-release; echo $VERSION_ID)_amd64.deb
```

**Arch Linux:** nulamp is in the signed [jpsutton pacman repository](https://github.com/jpsutton/arch-repo),
which always serves the latest release. Its setup script adds the repository, trusts its key (after
checking the fingerprint) and removes the old `[nulamp]` repository, which no longer gets updates:

```bash
curl -fsSLO https://jpsutton.github.io/arch-repo/setup.sh
bash setup.sh --install nulamp
```

To set it up by hand (and remove an old `[nulamp]` section from `/etc/pacman.conf`):

```bash
curl -sSfLo /tmp/jpsutton.asc https://jpsutton.github.io/arch-repo/jpsutton-signing-key.asc
sudo pacman-key --add /tmp/jpsutton.asc
sudo pacman-key --lsign-key 8476350364502FEDD331B66BEDB90079E3C73E41
printf '\n[jpsutton]\nServer = https://jpsutton.github.io/arch-repo/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu nulamp
```

**Windows:** run `nulamp-<version>-windows-x86_64-setup.exe`. It installs for your user by default
(no administrator prompt), adds a Start menu shortcut, opens `.wsz` skins with nulamp, and offers
nulamp for audio files and playlists under *Open with* and in *Default apps* without changing your
current defaults. The `.zip` is the same program without an installer. Both bundle the extra
codecs (an LGPL build of FFmpeg, and libopenmpt); the exact sources of the LGPL libraries are
attached to each release (`*-windows-msvc-lgpl-sources.tar.gz`). Builds are not code-signed yet, so
Windows SmartScreen may warn the first time.

**Other Linux distributions:** the AppImage needs glibc 2.39 or newer and bundles the extra codecs
(an LGPL build of FFmpeg and libopenmpt); the exact FFmpeg source is attached to each release.

```bash
chmod +x nulamp-*-x86_64.AppImage
./nulamp-*-x86_64.AppImage
```

## Building

Rust 1.88 or newer, and on Linux the development packages for FreeType, fontconfig, X11/xcb,
xkbcommon, Wayland, ALSA and D-Bus. libopenmpt is optional: without it, tracker modules are
disabled. So are the FFmpeg libraries (libavformat, libavcodec, libavutil, libswresample and
libswscale, 5.1 or newer): without them, video and the formats only FFmpeg reads are disabled. On
Windows, [`scripts/windows-codecs.sh`](scripts/windows-codecs.sh) (Git Bash, Visual Studio C++
tools) builds both with vcpkg and prints the `FFMPEG_DIR` and `OPENMPT_LIB_DIR` to build with. [`scripts/ci-deps.sh`](scripts/ci-deps.sh) lists the exact packages for Debian/Ubuntu
and macOS.

```bash
cargo build --release
./target/release/nulamp music/
```

On Linux nulamp runs through X11 (XWayland on Wayland sessions), because Wayland clients cannot
place their own windows, which docking needs. `NULAMP_WAYLAND=1` selects native Wayland.

Settings live in the platform config folder (`~/.config/nulamp` on Linux; `NULAMP_CONFIG_DIR`
overrides it). Skins go in its `skins` folder or can be dropped on a player window.
